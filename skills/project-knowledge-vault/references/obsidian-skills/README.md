# Vendored: kepano/obsidian-skills

These six skills are vendored from [kepano/obsidian-skills](https://github.com/kepano/obsidian-skills)
(MIT, © 2026 Steph Ango) at pinned commit **`3ccff5338ea700537839b21900aa5358a0402c98`**.

They are **embedded here** so `project-knowledge-vault` works standalone — the packaged
`project-knowledge-vault.skill` carries the full Obsidian open-format know-how with it, with no
other install required.

The same six are **also installed as first-class sibling skills** when the full
`project-knowledge-vault` plugin is installed (see the repo's `skills/` tree). Use the sibling
skills when they are available; fall back to the copies here otherwise.

filename `SKILL.md`, so leaving them named that way would register these embedded copies as six
